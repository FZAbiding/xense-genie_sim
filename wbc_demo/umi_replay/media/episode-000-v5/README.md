- IK 求解 P50 / P95 / 最大：2.498 / 4.941 / 6.275 ms；完整周期 9.575 / 13.377 / 16.716 ms。

- 夹爪开度最大误差 0.08420；最大腰 roll 0.16409°；底盘最大平移漂移 2.047 μm。

## 不代表什么

这是固定底盘、头部关节固定、双臂＋腰部＋夹爪的软实时位置级 IK 仿真，不是硬实时力矩 WBC。
首帧使用 BioIK，周期内使用本仓库的 Jacobian / OSQP 实现，位置与机构耦合、速度、离散加速度、离散碰撞保护保留。
仿真限速不代表真机认证；已知回放轨迹前瞻 33.3 ms，不代表预知未来的在线传感器输入。
虚拟 ego 仅同向，光学内外参未标定；没有重建任务物体，不能证明真实抓取成功。
