## 历史命令入口

以下入口现在运行的是修正版模型夹爪 EEF，并不重新生成本页旧虚拟 EEF 定义的结果。

首次完成下载和转换的机器，直接在仓库根目录运行：

```bash
mamba activate xense-wbc
export OMNI_KIT_ACCEPT_EULA=YES
bash wbc_demo/run.sh umi-all \
  --input wbc_demo/data/converted/episode-000.json \
  --output wbc_demo/logs/umi-my-next-run \
  --execute --speed 0.5
```

先关闭其他实验台与后端。输出目录必须是新目录。
不加 `--execute` 只预检；换成 `episode-005.json` 等可以测试其他段，但不能沿用第 0 段结果宣称它们也通过。
速度受关节约束与求解关节分支影响，重跑不保证相同 wall time。
